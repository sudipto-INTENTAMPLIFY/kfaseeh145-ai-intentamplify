# Intent Amplify Website

Canonical GTM website implementation repository.

## Release control

- Production deployment is **not authorized** by repository content alone.
- Staging implementation must follow the approved GTM release contract.
- Commercial treatment remains **Custom** until approved evidence exists.
- Website behavior must never create MQL, SQL, or Opportunity without approved qualification and CRM evidence.
- SuiteCRM integration remains disabled until Revenue Operations & CRM Control approval.

Implementation work is developed through staging branches and reviewed before any production release.
